# Probability

Currently  using a 3.5" diameter ball, but found that the foam baseballs are much more economical and available. 

<img width="1380" height="625" alt="image" src="https://github.com/user-attachments/assets/ebe5053c-fee5-44e6-b2f8-2f55fb86faa2" />


<img width="672" height="674" alt="image" src="https://github.com/user-attachments/assets/7b442089-c141-4fde-94fc-a3aea3823bab" />

The area to throw through is 3.3 inches x 3.3 inches = 10.89 ^2

The total surface area is 9.05 x 9.05 = 81.9 inches ^2

For every random throw that would put success at 13%. 

Using a ball of 2.86 inches in diameter, would results in a spot of 4.0x 4.0 = 16.0 inches ^2.

<img width="658" height="653" alt="image" src="https://github.com/user-attachments/assets/9a66233a-768a-44ea-b5a4-08b5d20164bd" />

This results in 16/81.9 = 19.5%.
